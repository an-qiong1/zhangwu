# 掌物 · 极简个人资产管理工具
一款纯本地、无广告、轻量简洁的开源资产管理 APP，基于 Android + Jetpack Compose 开发。

✨ 特点
- 纯本地运行，不上传任何数据，隐私安全
- 简洁 Material You 设计，流畅好用
- 支持资产记录、分类管理、心愿清单、数据备份
- 完全免费、无广告、无后台、无权限滥用

---

## 🚀 功能介绍
- 资产管理：快速添加、编辑、删除、管理个人物品
- 分类管理：自定义分类，清晰归类物品
- 心愿清单：记录想买的物品，标记进度
- 数据统计：查看资产价值、数量、分类占比
- 数据备份：一键导出/导入，换机不怕丢数据
- 深色模式 / 浅色模式自动适配

所有功能**完全离线**，不联网、不上传、不收集信息。
